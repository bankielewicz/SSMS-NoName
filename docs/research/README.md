# Research

Evidence gathered for NoName outside the planning chain. Nothing here is a decision: a finding enters the product only when `devforgeai:brainstorm`, `devforgeai:ui` or `devforgeai:prd` takes it up and records it in `docs/specs/`. Each file names its sources with URLs and read dates, marks what it could not verify as "claimed", uses fictional names only, and copies no third-party code.

## 2026-11-04: commercial SSMS extensions and the SSMS 22 surface

Asked by the owner: which ideas commercial SSMS extensions suggest, and which capabilities are real and buildable inside an SSMS 22 extension today, not aspirational. Four Sonnet 5.5 research subagents wrote one track each; the synthesis maps their findings onto BRN-001's ideas.

- [Synthesis: what the market and the SSMS 22 surface tell NoName](synthesis-ssms-extension-market-and-capabilities.md): start here. The idea-by-idea verdicts, what SSMS 22 already does natively, the three true gaps, the break timeline for the canary, consolidated new candidates, the probe expectations, and where the tracks disagree.
- [Track 1: Redgate and Quest (ApexSQL)](commercial-ssms-addins-redgate-apexsql.md): SQL Prompt's full feature set and AI data handling, Redgate's SSMS 22.x break timeline, the end of the ApexSQL add-in line.
- [Track 2: Devart (dbForge) and other vendors](commercial-ssms-addins-devart-and-others.md): SQL Complete, dbForge Monitor and the other add-ins, SSMSBoost and SSMS Tools Pack in full, SQLTreeo, VersionSQL, Plan Explorer, SQL Sage and the long tail, with each product's SSMS 22 status from its own page.
- [Track 3: open-source SSMS 21/22 extensions and the proven-API matrix](open-source-ssms-extensions-proven-apis.md): which SSMS-internal and VSSDK APIs shipping extensions use, confirmed on which SSMS build, with the gaps nobody has filled; the brokered contracts in the installed SSMS; licences.
- [Track 4: SSMS 22 extensibility surface, Microsoft's stance and native features](ssms22-extensibility-surface-and-native-features.md): Microsoft's quoted position on third-party extensions, the local install inspected, the surface matrix with the probe each row needs, and what SSMS 22.x ships natively that the suite must not rebuild.
