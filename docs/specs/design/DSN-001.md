# DSN-001 — NoName: an SSMS 22 suite of DBA tools around a redacted AI prompt builder: release design

## 1. Scope

NoName (a slug; the product name is open) is Bryan Ankielewicz's SSMS 22 extension suite for DBAs working on one SQL Server instance, around a hub that builds AI prompts locally with per-user redaction, as BRN-001 version 2 describes. This document records the eleven boards of the first release design in four flows, every one a desktop surface inside SSMS 22: instance-window (Overview, Live, Health facts), query-store (Query Store explorer, Plan inspector), incident-evidence (Error log reader, Deadlock viewer) and prompt-hub (Row to prompt, Prompt builder, Redaction preview, Redaction settings and presets). Seventeen promoted ideas have no board yet; section 5 lists them.
